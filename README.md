# GaymerSocial / .github

Org-wide default community health files for the [GaymerSocial](https://github.com/GaymerSocial) GitHub organization, formerly home of Gaymer.Social and Gaymer.Coffee — English-speaking Mastodon instances for LGBTQ+ gaymers, discontinued in September 2026. See [gaymer.social](https://gaymer.social) for the discontinuation notice.

Files placed in this repo (e.g. `profile/README.md`, issue/PR templates, a default `CONTRIBUTING.md`) are inherited by any repo in the org that doesn't provide its own. This repo currently just holds the org's baseline project scaffolding — nothing else has been added yet.

## Contact

Questions about the org or its repos: see the [Gaymer.Social](https://gaymer.social) instance itself for contact details.
