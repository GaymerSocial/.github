# GaymerSocial / .github

Org-wide default community health files for the [GaymerSocial](https://github.com/GaymerSocial) GitHub organization, formerly home of Gaymer.Social and Gaymer.Coffee — English-speaking Mastodon instances for LGBTQ+ gaymers, discontinued in September 2026. See [gaymer.social](https://gaymer.social) for the discontinuation notice.

Files placed in this repo (e.g. `profile/README.md`, issue/PR templates, a default `CONTRIBUTING.md`) are inherited by any repo in the org that doesn't provide its own.

- `profile/README.md` — renders as the public [GaymerSocial org profile page](https://github.com/GaymerSocial), carrying the same discontinuation notice

## Contact

Questions about the org or its repos: see [gaymer.social](https://gaymer.social) for the discontinuation notice and any contact details.
